# Ebook: Rahasia Istri Puas

Naskah ebook *Rahasia Istri Puas: Seni Memuliakan Istri Lahir dan Batin, dari Hati hingga Panggul* (buku 2, lanjutan *Rahasia Panggul Perkasa*).

- `Rahasia-Istri-Puas.docx`: naskah lengkap siap edit (Word).
- `naskah/`: sumber naskah per bagian (Markdown).
- `KERANGKA.md`: kerangka dan aturan penulisan.
- `build.py`: menggabungkan `naskah/*.md` menjadi file Word. Jalankan `python3 build.py` (butuh `pandoc` dan `python-docx`).

## Yang Perlu Dilengkapi Sebelum Terbit

1. Isian kosong: nama penulis, kota/tanggal kata pengantar, alamat dan kontak Syifa Balansu (Bab 16, Bab 20, Lampiran E), visi dan misi.
2. Deskripsi resmi layanan Body Balancing dan kebijakan terapis wanita untuk pasien istri (Bab 16, Lampiran E).
3. Kisah pasien asli berizin untuk menggantikan kisah ilustrasi: Pak Arif, Pak Yusuf, Pak Hasan, Pak Rizal, Pak Bayu, Bu Lina, Pak Andi.
4. Pemeriksaan terapis: Bagian IV, kotak "Pesan Terapis Biomekanik", glosarium, rekomendasi posisi ramah panggul (Bab 14).
5. Pemeriksaan ustadz/editor: semua nomor dan derajat hadits, terutama riwayat yang ditandai lemah (Bab 2, 10, 12) dan riwayat Ahmad di Bab 6.
6. Daftar pustaka: tahun terbit karya rujukan bertanda *[tahun]*.
