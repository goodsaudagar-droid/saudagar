# Ebook: Rahasia Panggul Perkasa

Naskah ebook *Rahasia Panggul Perkasa: Memahami Cara Kerja Ereksi dan Ejakulasi dari Sudut Pandang Biomekanik Syifa Balansu*.

- `Rahasia-Panggul-Perkasa.docx`: naskah lengkap siap edit (Word).
- `naskah/`: sumber naskah per bagian (Markdown).
- `build.py`: menggabungkan `naskah/*.md` menjadi file Word. Jalankan `python3 build.py` (butuh `pandoc` dan `python-docx`).

## Yang Perlu Dilengkapi Sebelum Cetak

1. Isian kosong: nama penulis, kota/tanggal kata pengantar, alamat dan kontak Syifa Balansu (Bab 15, Bab 20, Lampiran E), visi dan misi.
2. Kisah pasien asli berizin untuk menggantikan kisah ilustrasi: Pak Rudi, Pak Ahmad, Pak Fajar, Pak Hendra, Pak Dimas.
3. Pemeriksaan terapis: ejaan istilah dan glosarium, Bab 8, 9, 13, 17, serta kotak "Pesan Terapis Biomekanik".
4. Pemeriksaan ustadz/editor: semua nomor hadits.
5. Daftar pustaka: dua rujukan bertanda *[Lengkapi]* dan tahun materi dr. Sentot.
6. Ilustrasi: titik bertanda *[Ilustrasi: ...]* di naskah.
